# Strut Studio

The desktop editor for Strut. This app is built with Tauri v2, React, TypeScript, and the Rust crates in the repository root.

## Commands

Run from the repository root:

```powershell
npm install
npm run check
npm run test
npm run studio:dev
```

Run from this folder when debugging only the frontend:

```powershell
npm run check
npm run build
npm run tauri -- dev
```

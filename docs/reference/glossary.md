# Glossary

## Artboard

The canvas for one animation component.

## Binding

A property that app code can control at runtime, such as label text or accent color.

## Event

A message emitted by an animation, such as `completed` or `submit`.

## Input

A value used by a state machine. Inputs can be booleans, numbers, triggers, or enums.

## Plan Mode

The AI workflow where Strut creates rough 2D directions before building a full animation.

## State Machine

Interaction logic that decides which animation state should run.

## Timeline

A time-based animation track.

## `.strut`

The open file format for Strut animation components.

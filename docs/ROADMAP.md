# Roadmap

The roadmap is organized around reviewable vertical slices. Each phase should leave the project easier to run, inspect, and contribute to.

## Phase 0: Repository Identity

- README
- brand assets
- license
- contribution guide
- architecture docs
- MVP scope
- manual review guide
- GitHub topic list

## Phase 1: Scaffold

- Tauri Studio app
- Rust workspace
- TypeScript workspace
- root scripts
- CI-ready check commands
- basic desktop shell

## Phase 2: Format And Core

- scene graph
- timelines
- state machines
- bindings
- events
- `.strut` manifest/document validation
- sample document

## Phase 3: Preview And Runtime

- GPU-backed viewport abstraction
- first renderer path
- timeline playback
- state machine input control
- runtime web package
- React wrapper

## Phase 4: Agent Engine

- provider router
- Ollama adapter
- OpenAI-compatible adapter
- local agent adapter interface
- tool operation schema
- context preview
- verifier integration

## Phase 5: Import And Plan Mode

- SVG import
- raster mockup pipeline design
- 2D sketch generation workflow
- motion storyboard output
- user approval before full generation

## Phase 6: Public Alpha

- packaged desktop builds
- example gallery
- API docs
- contributor issues
- release notes
- project website

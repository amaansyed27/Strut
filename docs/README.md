# Strut Docs

Welcome to the Strut docs. These pages are for people who want to design, animate, export, and ship interactive motion components with Strut.

Strut is pre-alpha, so some screenshots and commands will change. The main ideas are stable: open files, desktop-first editing, AI-assisted creation, local control, and runtime-ready exports.

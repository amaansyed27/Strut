# What Is Strut?

Strut is an open-source desktop app for creating interactive motion components.

A Strut file can be a button, loader, onboarding illustration, empty state, icon, badge, chart accent, or game-like UI moment. It can include artwork, animation timelines, state machines, inputs, bindings, and events.

## What You Can Make

- Buttons with hover, press, loading, success, and error states.
- Icons that react to app state.
- Loading and progress components.
- Onboarding illustrations.
- Small product animations that developers can control from React.
- Motion components created from SVGs, screenshots, sketches, or prompts.

## Why It Exists

Most motion tools are either great for making videos or great for making static assets. Product teams need something different: motion that is editable, interactive, testable, and easy to ship inside apps.

Strut focuses on that workflow:

```txt
idea or mockup
  -> editable motion component
  -> preview and verify
  -> export
  -> control from app code
```

## What Makes Strut Different

- It is open source.
- It uses an open `.strut` file format.
- It runs as a desktop app on Windows, macOS, and Linux.
- It is designed for local GPU acceleration.
- It can use cloud AI providers through BYOK.
- It can use local AI through Ollama or OpenAI-compatible local servers.
- It can connect to local coding agents.
- It can sketch first before generating a full design.

## What Strut Is Not

Strut is not a video editor. It is not a full illustration suite. It is not a web-only SaaS tool. It is a motion component studio for product teams.

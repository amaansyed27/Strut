# Plan Mode

Plan Mode is what Strut uses when you do not have a mockup yet.

Instead of jumping directly from a prompt to a polished animation, Strut first creates rough 2D directions. You review those sketches, choose a direction, and only then ask Strut to build the full editable animation.

## Example

Prompt:

```txt
Create a friendly payment success animation for a checkout flow.
```

Plan Mode might create:

1. A checkmark burst.
2. A receipt card flip.
3. A coin dropping into a wallet.
4. A progress ring turning into a success badge.

Each option is a sketch, not a final asset.

## Why Sketch First

Sketching first keeps AI generation controllable. It lets you decide the concept before Strut spends time building layers, timelines, states, and bindings.

## What Plan Mode Produces

- rough 2D sketches
- motion storyboards
- state diagrams
- timeline thumbnails
- interaction maps

After you approve a direction, Strut converts the chosen plan into a structured `.strut` document.
